# NYC Motor Vehicle Collisions - Power BI Dashboard

## Overview
Interactive Power BI dashboard analyzing 238,421 motor vehicle collisions 
reported by the NYC Police Department from January 2021 to April 2023.

## Project Structure
- `data/` — NYC Collisions dataset (CSV)
- `reports/` — Power BI file (.pbix) and project report
- `images/` — Dashboard screenshots

## Tools & Technologies
- Power BI
- DAX (calculated columns and measures)
- Data modeling and visualization

## Key Insights
- Collision trends by month, day of week, and hour
- Top contributing factors to collisions and fatalities
- Person demographics (injured/killed by category)
- Top 7 vehicle types involved in collisions
- Street-level collision analysis
